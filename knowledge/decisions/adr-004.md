# ADR-004: Evidence attachments in archived Allure reports

*   **Status**: Accepted
*   **Date**: 2026-09-27
*   **Related Files**: `fixtures/test-fixtures.js`, `playwright.config.js`, `scripts/run-allure.js`

## Context

Archived reports must include visual and execution evidence for passed as well as failed tests.

## Decision

Attach a final full-page screenshot through the shared Playwright fixture after every test and record a Playwright trace for every test. The standalone Allure report embeds these attachments.

## Rationale

Consistent evidence makes an archived report useful for later review and sharing without rerunning a test.

## Consequences

Each archive uses more disk space and test runs take slightly longer. Trace viewing requires the Playwright Trace Viewer to load in the browser.

## Alternatives Considered

* Capture artifacts only on failure: rejected because passing runs would have no visual record.
* Add screenshots separately in every spec: rejected because it would duplicate implementation and lead to inconsistent coverage.

## Review Notes

Verify a generated report shows a `Final page screenshot` attachment and a Playwright trace for a passing test.
