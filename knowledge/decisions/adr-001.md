# ADR-001: Timestamped local Allure report archive

*   **Status**: Superseded by ADR-002
*   **Date**: 2026-09-27
*   **Related Files**: `playwright.config.js`, `package.json`, `scripts/run-allure.js`, `scripts/open-latest-allure-report.js`, `.gitignore`

## Context

Overwriting a single Allure report prevents comparison and review of earlier test runs. Generated test artifacts must remain local and must not be committed to Git.

## Decision

Each `npm test` run stores its Allure results and generated HTML report in `allure-history/YYYY-MM-DD_HH-mm-ss/`. The newest saved report opens via `npm run allure:open`. The archive directory is ignored by Git.

## Rationale

Timestamped folders preserve a self-contained report for each run while requiring no external report server or manual folder management.

## Consequences

Historical reports consume local disk space and require periodic manual cleanup if many runs are retained. Reports are intentionally unavailable after a fresh clone because they are not source-controlled.

## Alternatives Considered

* Overwrite `allure-report/`: rejected because earlier reports are lost.
* Commit generated reports: rejected because generated artifacts would enlarge the repository.
* Use external report storage: deferred because it requires additional infrastructure and credentials.

## Review Notes

Verify that every run creates a timestamped `results` and `report` folder and that `allure-history/` remains ignored by Git.
